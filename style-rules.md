# Style rules (apply to all skills)

- No em dashes. Use commas, periods or colons.
- Cut stock phrases: "game-changer", "unlock", "dive in", "in today's fast-paced world", "let's face it", "here's the thing".
- No invisible or zero-width characters.
- Short sentences. Concrete nouns. Specific numbers only when the user supplied them.
- Match the voice in `data/account.md`. When unsure, write like a smart friend explaining something.
- Run a self-check before showing any draft: scan for the items above and fix them.
- Never invent stats, testimonials, results or quotes.
